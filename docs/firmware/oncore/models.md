# Oncore messages by model

Generated by `smartclock-cli dump-oncore --models` from the images
in `third_party/firmware/` that talk to an Oncore.  Run `make docs`
to regenerate; a test fails if this file and the images disagree.
`README.md` here says how the tables are read; `../gps.md` is the
link itself.

A cell is `s` where a script or polling list sets the message, `q`
where one queries it, `d` where the table has a decoder for it, `-`
where the table holds it and none of these, blank where it does not
hold it.  Code can also request a message by its index, which this
does not see; `../gps.md` names the requests found.
